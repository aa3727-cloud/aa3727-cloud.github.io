Lennox install pricebook

2026, in progress

Building the Lennox install pricebook in ServiceTitan as the company shifts its install sales to Lennox. I organized equipment into Good, Better, and Best tiers, defined matched-system bundles (furnace, coil, and condenser; heat pump and air handler; dual fuel), set scope rules that keep incompatible pairings out, and run bulk imports with a review after each round so technicians can quote complete systems from an iPad.

ToolsServiceTitan, Excel, ServiceTitan import templates
